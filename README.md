# Palindrome Checker

A simple web application built with HTML, CSS, and JavaScript that checks whether a word or phrase is a palindrome.

A palindrome is a word, phrase, number, or sequence that reads the same backward as forward when spaces, punctuation, and capitalization are ignored.

## Features

- Check if a word or phrase is a palindrome
- Ignores spaces and punctuation
- Ignores letter casing
- Provides instant feedback to the user
- Clean and responsive user interface
